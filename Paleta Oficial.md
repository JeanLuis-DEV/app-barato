# DESIGN SYSTEM — APPS SIMPLES
## Paleta Oficial v1.0

### Cores principais

#262933 — Fundo principal
Uso:
- fundo padrão dos aplicativos
- telas
- áreas principais

#CCAA4B — Dourado da marca
Uso:
- botões principais
- elementos selecionados
- destaques
- bordas de foco
- ícones importantes
- resultados principais

#FFFFFF — Branco
Uso:
- textos principais sobre fundo escuro
- títulos
- ícones neutros
- elementos que precisam de alto contraste

#585858 — Cinza
Uso:
- bordas
- divisores
- elementos desabilitados
- informações de menor importância

#000000 — Preto
Uso:
- texto sobre botões dourados
- sombras
- contraste
- elementos escuros específicos
